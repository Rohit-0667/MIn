**Mintlify Website Clone**


A frontend clone of the Mintlify landing page, built using pure HTML and CSS.
This project focuses on replicating the layout, styling, and overall user experience of the Mintlify homepage.

DISCLAIMER:
This project is created only for learning and practice purposes.
All branding, images, and design inspiration belong to Mintlify.

TECH STACK:
- HTML5
- CSS3
- Google Fonts (Inter)
- No JavaScript
- No frameworks or libraries

PROJECT STRUCTURE:
mintlify-clone/
├── index.html
├── mintlify.css
├── Images/
└── README.md

FEATURES:
- Responsive navigation bar
- Hero section with call-to-action
- Company logos section
- Feature cards layout
- Enterprise & customer sections
- Modern dark UI design
- Clean and structured CSS

HOW TO RUN LOCALLY:
1. Clone the repository
2. Open the folder in VS Code
3. Open index.html in browser

LEARNING OUTCOMES:
- Improved CSS layout skills
- Understanding real-world UI structure
- Experience cloning professional websites
